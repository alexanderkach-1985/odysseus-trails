# Odysseus Trails: автопубликация в Instagram

Каждый день в 08:00 и 19:00 по Хараре GitHub сам публикует в @odysseus.trails следующий пост (два в день): фото и подпись на русском и английском. Посты идут по порядку маршрута. Фото, которые вы не загрузили (удалили из подборки), пропускаются.

Подборка-кандидат: альбом «Odysseus Trails» в «Фото» на Mac (72 фото). Удалите лишнее, остальное загрузите сюда.

## Как загрузить фото
На этой странице: **Add file → Upload files**. Перетащите или выберите фото, затем нажмите **Commit changes**.
- Имена файлов не важны. Помощник сам узнаёт каждое фото по содержимому и ставит его на свой день.
- HEIC, JPG и PNG подходят. Размер, пропорции и удаление геометок помощник делает сам.
- Фото не обрезайте: дату на Нью-Йорке и Ниагаре помощник срежет сам.
- Через минуту во вкладке **Actions** видно, какие фото узнаны и каких ещё не хватает.

## Ключ Instagram (один раз)
1. developers.facebook.com → Create App → тип Business → продукт Instagram → «API setup with Instagram login» → Add account (odysseus.trails) → **Generate token**.
2. Здесь: **Settings → Secrets and variables → Actions → New repository secret**:
   - `IG_USER_ID`: Instagram User ID
   - `IG_ACCESS_TOKEN`: токен
   - по желанию `TG_BOT_TOKEN` и `TG_CHAT_ID`, чтобы получать отчёт в Telegram

Ключ системного пользователя бессрочный, обновлять его не нужно.

## Проверка
Actions → «Публикация в Instagram» → Run workflow (по умолчанию стоит галочка «Только проверка»).
